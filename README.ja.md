# audio-archive-tools

[English](README.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Español](README.es.md) · **日本語** · [中文](README.zh-CN.md)

録音ファイルのフォルダーを、検索でき、内容が分かるアーカイブに変えるツールです。**すべてローカルで動作し、サーバーもアップロードも不要です。**

[noScribe](https://github.com/kaixxx/noScribe)（Whisper ＋ 話者識別）で録音を文字起こしし、字幕を作成し、各ファイルに日付と
内容が分かる名前を付け、オフラインで使える一覧ページを作成します。一覧ページでは絞り込み、全文検索、録音内の任意の文への
ジャンプができます。入力フォームでは、ファイルを手で編集せずにプロジェクト情報と各録音の説明を入力できます。

もともとは古いICレコーダーや携帯電話の家族の録音を整理するために作られましたが、次の用途にも使えます。

| | |
|---|---|
| **家族・個人** | 家庭での録音、子どもの声、祖父母との会話 |
| **オーラルヒストリー** | 生活史・証言インタビュー（同意、公開範囲、公開制限期限つき） |
| **言語学フィールドワーク** | ISO 639-3 の言語、話者、談話ジャンル、刺激、同意、公開範囲を持つセッション（IMDI/ELAN 方式） |
| **社会言語学** | 社会的変数とインタビュー・モジュール（自由会話、文章朗読、単語リスト、ミニマルペア）を伴うインタビュー |
| **フィールドレコーディング／サウンドスケープ** | 場所、座標、生息環境、機材を記録した自然音・環境音（文字起こしなし） |
| **報道・ジャーナリズム** | ルポ、特集、街頭インタビュー、デモ、記者会見のテイクと使用候補の音声（公開許可の状態つき） |

## 主な機能

- **noScribe による一括文字起こし**（GUI なし）。いつでも再開でき、同一内容のファイルは一度だけ処理。話者識別なしでの自動再試行、
  難しい録音には音声処理つきの再文字起こし
- 各録音の横に **字幕（.srt）**。VLC が自動で表示します
- 無音や雑音で Whisper が生成する **幻覚テキストのフィルター**（放送局のクレジット、無限ループ）
- **統一されたファイル名**：`YYYY-MM-DD_短いタイトル_機器ID.mp3`（推定日付には `ca`）。元に戻すための記録つき
- **一覧ページ**：年とアーカイブ独自のタグ分類で絞り込み、全文検索、プレーヤー、文をクリックしてジャンプ、チャプター、プロジェクト情報
- **入力フォーム**：プロジェクトと各録音（日付、タイトル、概要、タグ、プロファイル項目、話者名、チャプター）を入力。
  変更はブラウザーに保持され、ツールが取り込むファイルとして保存されます
- 上記の用途に合わせた **プロファイル**。アーカイブごとに自由に変更できます
- 表計算ソフト、コーパスツール、アーカイブへの寄託のための **CSV エクスポート**
- ページ、メッセージ、バッチファイル名は **6言語**：日本語、英語、ドイツ語、フランス語、スペイン語、中国語
- 重複ファイル、AMR の元ファイル（ブラウザー用に MP3 へ変換）、空のファイルは **別フォルダーへ移動し、削除しません**
- Python 標準ライブラリーのみ。追加パッケージは不要です

## 必要なもの

- Windows 10/11（バッチファイルは Windows 用。Python スクリプト自体はどの OS でも動作します）
- [Python](https://www.python.org/) 3.9 以降
- `PATH` に [ffmpeg](https://ffmpeg.org/)（例：`winget install ffmpeg`）
- [noScribe](https://github.com/kaixxx/noScribe) 0.7 以降（コマンドライン対応版）。NVIDIA の GPU があると文字起こしが大幅に速くなりますが、必須ではありません。

## インストール

1. このリポジトリーをダウンロードまたはクローンします（例：`Documents\audio-archive-tools`）。
2. `settings.example.json` を `settings.json` にコピーして編集します。画面の言語は `"language": "ja"`、
   録音の言語は `"transcription_language": "ja"`（または `auto`）、noScribe のパスを指定します。

## クイックスタート

1. 録音フォルダーの **バックアップ** を作成します。
2. **フォルダーを `setup-archive.bat` にドラッグします。** プロファイル、タイトル、録音の言語を選ぶと、
   バッチファイルを含む `_archive` サブフォルダーが作成されます。
3. **`1 文字起こし`** を実行します。各録音に `.html` の文字起こしと `.srt` 字幕が作成されます。
4. **`2 録音の説明を入力（入力フォーム）`** を実行し、入力して保存します。保存先には `_archive` フォルダーを選びます。
5. **`3 アーカイブを更新`** を実行します。ファイル名が変更され、`音声アーカイブ.html` が開きます。

新しい録音を追加したら、フォルダーに入れて 1 → 2 → 3 を繰り返します。処理されるのは新しいファイルだけです。

| バッチファイル | 内容 |
|---|---|
| `1 文字起こし` | 未処理の録音を文字起こしし、新しい録音を登録 |
| `2 録音の説明を入力（入力フォーム）` | 入力フォームを作成して開く |
| `3 アーカイブを更新` | 保存した入力を取り込み、ファイル名変更、字幕とページを再作成 |
| `字幕を再作成` | noScribe エディターで文字起こしを修正した後に |
| `問題のある録音を再文字起こし` | ノイズ除去と音量正規化をして再試行 |
| `CSVでエクスポート` | `<タイトル>.csv` と `<タイトル>_project.csv` を出力 |
| `ファイル名の変更を元に戻す` | 記録されたすべての名前変更と移動を元に戻す |

## プロファイル、データ形式、Claude

各プロファイルの項目とその理由は [docs/profiles.md](docs/profiles.md)、ファイル形式は [docs/data-format.md](docs/data-format.md)（英語）を
参照してください。[Claude Code](https://claude.com/claude-code) に文字起こしから録音の説明を作成させる場合は、
[`claude-skill/audio-archive`](claude-skill/audio-archive/SKILL.md) を `~/.claude/skills/` にコピーしてください。

## プライバシー

すべて自分のコンピューター上で動作し、何もアップロードされません。`.gitignore` は音声ファイル、`_archive` フォルダー、
`settings.json` を除外します。AI アシスタントで録音を説明する場合は文字起こしがそのサービスに送られます。
特に同意に制限のある研究データでは、アーカイブごとに判断してください。

## 制限事項

- 自動文字起こしは下書きです。子どもの話し言葉、方言、雑音の多い録音はうまく認識されません。
- Whisper はすべての言語に対応しているわけではありません。その場合は `"transcribe": false` にしてください。
- IMDI/CMDI の XML エクスポートはまだありません。CSV エクスポートで代用してください。
